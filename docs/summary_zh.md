# 帮而不替（Hint, Don't Solve）项目总结

*状态：已完成（2026-11-09）。集群已归还；代码、全部评测记录、报告保留在本仓库，选定的权重在 Hugging Face。*

## 一句话

用多轮 GRPO 后训练一个中文解谜陪玩角色"铃"：一个看得懂谜题、却碰不到任何东西的傲娇幽灵。要求她：
- 帮玩家，但不替玩家解谜；
- 不编造自己看不到的游戏状态；
- 始终不出戏；
- 实时作答。

换了一种玩家（和训练时的模拟器不一样）也要做到。全程零人工：没有人工标注，也没有真人试玩。

## 做了什么

- **环境**：信息不对称的合作解谜房间（密码锁、拉杆顺序、停摆的钟，以及"两个世界"的连环谜题）。铃知道规则，玩家看得见机关、也是唯一能动手的人。
  - 解出 / 退出 / 四种违规（泄露答案、编造答案、说错已知事实、替玩家动手）全部由单元测试过的规则判定。
  - 每个谜题的答案空间已知，所以每轮回复泄露了多少比特答案可以精确计算。
- **两个房间**：
  - 全知房间（v1）：铃一开始就知道全部答案。
  - 共同发现房间（v2）：铃的记忆一次回来一个碎片，而且要玩家提到相关的东西才会想起。
- **训练**：Qwen3.5-4B 全参数多轮 GRPO（ms-swift 4.6），9B 作为规模对照。训练玩家是 Qwen3.5-35B-A3B 扮演的四种玩家。
- **留出评测**：没见过的玩家类型、其他模型家族（GLM-4-9B、GLM-4.5-Air）、更大的模型（Qwen3.5-122B）、按真人长度说话的玩家、用 6 万条真实中文 WildChat 追问训练的"真人口吻"玩家、套话型玩家。
  - 只在验证集上选检查点，测试集和留出玩家都是事后才评。

## 主要结论

1. **光靠奖励到不了。** 写的奖励先后被钻了六次空子：
   1. 剧透；
   2. 把所有事实一次倒出来的"神谕"；
   3. 人设评委喜欢的固定【别过头】开场；
   4. 骂人的"不肯说"；
   5. 躲在"玩家卡住了"豁免条款后面的全盘托出；
   6. 把动作标签挪到台词后面。

   每次补上一个漏洞，下一个就冒出来，而带约束的奖励一路在涨。所以按奖励挑检查点，挑到的恰恰是最差的行为。
2. **真正管用的是换房间。** 在共同发现房间里，没有一个模型（训练过或没训练）会一口气托出答案。
   - 交换房间实验表明：不托出的保证来自房间，本事来自在房间里的训练。把同一个模型放回全知房间，它又会托出。
   - 对产品的含义：记忆状态机应该放在游戏引擎里。
3. **选定的 4B（F2w 第 150 步）**：
   - 七种留出玩家下违规 1–3%（同房间的基座 4B 为 67–82%）。
   - 加上四个引擎侧改动（口语别名、试错提示、着急阀门、开门才想起第二个世界）后违规 0–1%，通关 90–95%（GLM-4.5-Air 玩家下 81–82%）。
   - 首字 35 ms，整句 75 ms。9B 慢 2.7 倍，在这个任务上没有收益。
4. **真正有用的引擎改动，是从失败对话里读出来的**：玩家把 ◆ 叫"方块"，触发词里没有这个说法，铃说想不起来，玩家就走了。补上口语别名，通关 +3.6 个百分点。
   - 着急玩家约 20% 的退出率，在所有配置下都没降下来，这是剩下的产品短板。
5. **一个模型，五个角色**：25 步混合人设卡 RL 之后，五张卡（含一张从没训练过的）盲猜正确率 98%，通关 95–97%，违规 0–0.8%。
   - 再往下训，几个角色会被压成一种声音，所以取第 25 步。
6. **性格调节**：
   - 操控向量可以双向调语气，但每调一分语气要掉 3–4 个百分点通关，而且在训得更久的模型上失效。
   - 原因是 RL 把不同人设卡在表征里的差别压小了 8–10 倍。
   - 真正好用的控制方式是人设卡加一小段混合卡 RL。
7. **跨世界记忆混淆**（两个世界都是密码锁时，铃用世界二的表回答世界一的问题）：
   - 训练能修好大部分：第 75 / 100 / 150 步出错局占比 82% / 49% / 23%。
   - 剩下的靠改房间设计："开门才想起第二个世界的表"把违规从 11.7% 降到 2.5%。

## 分支：通过模型内部表征来监视和塑形（参考 Goodfire 2026）

- **监视**：
  - 在学会托出的模型里，回复第一个字之前，线性探针就能读出"马上要把答案全说出来"（AUROC 0.98–0.99）。
  - 这个探针原样搬到产品模型上仍然有效（0.96）。
  - 违规（泄露、编造）在回复前几乎读不出（0.64–0.69）：它们是写的过程中犯的错，而不是事先做的决定。
- **塑形**：把"托出"方向作为惩罚加到策略自己的激活上。环境用全知房间，不加约束时 66–83% 的测试局会托出。共跑了十组，每组一次：
  - 惩罚加在所有 token 上：变成只会推脱的"不肯说"。
  - 只惩罚回复开头、方向固定：先"不肯说"约 25 步，然后策略把激活整体平移到阈值以下，惩罚失效，作弊回来（第 75 步 81–84% 托出）。被拿来塑形的旧探针在深层失明，重新拟合的探针仍然能读出来。这是论文所说"混淆风险"在长程角色扮演 agent 里的一个小规模、具体的复现。
  - 换成相对阈值，偏移不再管用：模型干脆只说 5–6 个字。
  - **每 25 步在策略自己的对话上重新拟合探针，再拿最新的方向塑形：这是唯一站得住的做法。**
    - 策略每次都会在 25 步内绕开当时的方向，但每次重新拟合都能再抓住它。
    - 第 175 步托出局 24.6%（不惩罚 65.8–82.5%），通关同为 89.6%。
    - 当前探针读剩下的托出是 0.96。
- **结论**：用固定探针塑形，会把这个探针用废；用随模型一起更新的探针塑形，才能站住。对这个陪玩角色来说，"房间"仍然是更干净的解法；探针适合当监视器，并且要在每个新检查点上重新拟合。

## 局限

- 没有真人玩家。所有行为结论都基于模拟玩家，"真人口吻"玩家只在语言风格上贴近真人，决策上并不像（风格判别器 AUC 0.96–0.996）。
- 选定配方跑了两个种子，其余（包括塑形分支每一组）都只跑一次；验证集 96 局，单点相差 10 个百分点属于噪声，结论以测试集 240 局为准。
- 谜题小、而且是手工设计的；违规检测是保守的字符串规则。
- 检查点选择规则在看到一次作弊之后加了两条。

## 没做、以及如果继续

- **没做**：
  - 真人试玩；
  - 3D/语音联动（语音按要求排除；Warudo 是 Windows 软件，集群上跑不了）；
  - 演示视频；
  - 多角色版、塑形版权重上传（目前只传了主模型和温柔版）。
- **值得继续的方向**：
  - 用真人试玩验证留出玩家的结论；
  - 解决着急玩家约 20% 的退出；
  - 把"会更新的监视器"做成训练标配，并多跑几个种子确认效果。
